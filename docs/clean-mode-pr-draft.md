# PR 标题

feat(ui): add native clean mode for feed playback

# PR 正文

新增默认关闭的“清爽模式”：视频播放时通过抖音原生清屏命令隐藏播放页控件，保留视频、进度条和已开启的弹幕；暂停时恢复控件，继续播放时再次清屏。修改开关后需重启抖音。

## 功能行为

- 根据播放、暂停、滚动和页面生命周期管理清屏状态；推荐流中的直播预览卡片也保持清屏。完整直播间仍由宿主自身处理。
- 使用原生占位布局适配路径，使隐藏底栏后的空间交还视频页面。
- 在主页保持系统全屏；暂停视频时仍保留系统全屏，滑动可临时呼出系统栏。
- 在清爽播放期间约束主页顶部、阴影和底栏的最终显示请求，处理评论关闭后后续回调重新显示栏位的情况；暂停或离开时交还宿主控制。
- 通过原生命令白名单保留弹幕外层，不依赖传统或 Compose 渲染器的视图附着时机；遵循抖音自身的弹幕开关。

## 实现与维护

调用 `CleanModeService`，通过独立 caller 提交和撤销本模块清屏命令，使用宿主已有的状态管理与布局适配。播放状态、系统窗口和主页栏兼容分别维护，页面引用使用弱引用。

弹幕保留发生在命令进入服务之前：复用宿主 `lpp_play_control` 命令的弹幕白名单策略，覆盖 `toggleCleanMode` 的两个重载及 `toggleCleanModeInVH`。进入、退出和反向命令均补齐缺失项，避免重复追加。宿主后续重放命令时自然继承该策略。

移除旧弹幕视图 Hook，同时移除生成视图 ID、弹幕视图集合、附着监听及祖先隐藏请求拆分。弹幕资源 ID 从宿主策略动态取得；工厂定位和策略内容均进行校验，解析失败时记录错误并跳过弹幕策略，不使用固定资源 ID 回退。弹幕策略映射与核心清屏映射分别处理。

本实现属于原生命令/状态层适配，并非完全的数据层实现。系统全屏仍需修改窗口状态；评论动画后的主页栏兼容仍约束最终渲染参数，但不改写宿主优先级请求表。这两部分保留为独立、限定作用范围的兼容代码，便于 review 与后续替换。

新增符号集中解析并存入现有 HookInfo 缓存。基于上游 0.15.1（main `1bab889`），保留上游导航数据源字段 66/67，清爽映射使用 68/69；移除的旧弹幕与导航字段设为 reserved。合入时需更新模块版本，使旧映射缓存失效。主页栏映射失败时禁用该保护，基础原生清屏仍可运行。

## 新增文件职责

新增 7 个生产 Kotlin 文件，分别负责播放状态、原生符号、弹幕策略及窗口/主页栏兼容：

| 文件 | 职责 |
| --- | --- |
| `hook/ui/CleanModeHooker.kt` | 接收播放、暂停、选页、滚动及生命周期回调；管理所属 panel/fragment，提交、重申和撤销本模块原生清屏命令，并调用宿主布局适配。 |
| `hook/ui/CleanModePlaybackState.kt` | 纯 Kotlin 状态转换，处理播放/暂停、滚动中的旧视频暂停、直播预览和离开页面；由独立单元测试覆盖。 |
| `hook/ui/CleanModeWindowHooker.kt` | 管理主页 `MainActivity` 的系统全屏，在恢复、获得焦点及窗口 flags 更新时维持系统栏隐藏，允许手势临时呼出系统栏。 |
| `hook/ui/CleanModeChromeHooker.kt` | 在当前清爽页面所属 Activity 内约束主页顶部、阴影和底栏的最终显示请求；弱引用保存被拦截的待显示请求，在暂停或退出时恢复。 |
| `hook/NativeCleanModeSymbols.kt` | 集中声明宿主入口、事件码和命令位；通过 DexKit 解析原生服务、命令、弹幕策略工厂及混淆字段，校验策略内容并生成缓存映射。 |
| `hook/NativeCleanModeChromeSymbols.kt` | 通过 DexKit 定位主页栏最终渲染方法、HomePageUIService 单例及资源 ID getter，生成主页栏保护所需的缓存映射。 |
| `hook/ui/DanmakuCleanModeHooker.kt` | 在服务接收清屏命令前补齐原生弹幕白名单，覆盖进入与退出路径并去重；替代旧 DanmakuViewHooker，不操作弹幕视图。 |

上述路径均相对于 `app/src/main/java/io/github/twyora/douyinenhancer/`。Hook 注册由现有注解处理器生成，无需修改 HookEntry。

新增 2 个测试文件：`CleanModePlaybackStateTest` 覆盖播放、滚动和页面状态转换；`NativeDanmakuPolicyTest` 校验原生弹幕策略，拒绝生成视图 ID、空策略、额外控件及错误类型。
